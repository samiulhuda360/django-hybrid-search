Networking

Custom domains

Every app gets an address ending in acme.app. You can also serve it from your own domain name.

Adding a domain

Run acme domains add www.example.com or use the dashboard under Settings, Domains. The command prints the DNS record to create at your domain registrar.

DNS records

For a subdomain such as www, create a CNAME record pointing to your app's acme.app address. For an apex domain without www, create the A and AAAA records shown in the dashboard. DNS changes can take up to 48 hours to reach everyone, but usually take minutes.

Checking progress

Run acme domains check to see whether the records are correct and whether the certificate has been issued.
