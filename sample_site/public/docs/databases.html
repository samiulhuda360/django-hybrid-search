Data

Managed PostgreSQL

Acme Deploy can run a PostgreSQL database for your app.

Creating a database

Run acme db create. The connection address is stored in the DATABASE_URL variable of the project, so your app can connect without extra setup.

Connecting from your computer

Run acme db shell to open a psql session, or acme db proxy to forward the database to a local port for your own tools.

Upgrading

Database plans can be changed in the dashboard. Moving to a bigger plan takes a short read-only period of under a minute.
