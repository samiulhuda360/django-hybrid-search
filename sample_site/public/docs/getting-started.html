Basics

Quick start

Acme Deploy runs your web application on managed servers. This guide takes you from an empty account to a live URL in about ten minutes.

Before you begin

You need an Acme Deploy account, a Git repository with your application, and a terminal. Any language that listens on an HTTP port works, including Python, Node.js, Go, Ruby and Java.

Your first deploy

Install the command-line tool, run acme login, then run acme init inside your project folder. The init command detects your language, writes an acme.toml file and creates a project. Run acme deploy to upload the code. When the build finishes, the command prints the public address of your app, ending in acme.app.

Next steps

Add environment variables for your settings, connect a custom domain, and turn on alerts so you hear about problems before your users do.
