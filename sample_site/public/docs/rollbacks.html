Deploys

Roll back a release

Every successful deploy creates a release that you can return to.

Rolling back

Run acme rollback to return to the previous release, or acme rollback v42 to pick a specific one. In the dashboard open Deploys, find the release and choose Roll back. The old image starts again without a new build, so a rollback usually takes under a minute.

What is not rolled back

A rollback restores your code and its settings at that time. It does not undo database migrations or changes to stored files. Write migrations that work with both the old and the new code, so you can always go back safely.

Keeping releases

The last 50 releases are kept for each project.
