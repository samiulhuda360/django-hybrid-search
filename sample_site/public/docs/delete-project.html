Projects

Delete a project

Deleting a project stops its apps and removes its data.

Before you delete

Download any database backups and files you want to keep. Remove your custom domains from the project so the DNS records can be reused elsewhere.

Deleting

Open the project settings and choose Delete project, then type the project name to confirm. Only owners and admins can do this.

What happens to the data

Apps stop immediately. Databases, buckets and backups are kept for 7 days in case you change your mind, and then erased permanently. Contact support within those 7 days to restore the project.
